# Staging seven-day soak plan

Start date: 2026-08-17

The release gate requires 168 real elapsed hours of continuous staging evidence. The hourly sampler checks the public frontend, product frontend, edge health, API health, aggregate readiness, and Collaboration health endpoints.

Acceptance criteria:

- At least 168 hours between the first and final samples.
- At least 160 successful hourly samples.
- No failed endpoint samples.
- No sampling gap longer than 90 minutes.
- Final evidence generated by `npm run verify:staging:soak-finalize`.

Run one sample with `npm run verify:staging:soak-sample`. Raw samples are retained under the ignored `.tmp/staging-soak` directory. The tracked evidence file is created only after every criterion passes. Production approval must remain false while the soak is in progress.
