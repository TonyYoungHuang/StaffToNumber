# 激活码直接登录

买家入口仍为 <https://app.scoretransposer.com/cn>。输入激活码即可建立并登录对应账户，无需填写邮箱、设置密码或注册；登录后显示套餐、到期时间、额度与工具入口。

## 账户和授权

- 首次登录在同一数据库事务内建立账户、占用激活码、开通既有套餐。失败一起回滚；PostgreSQL 对激活码加行锁，防止重复建号。使用期限仍按原套餐计算。
- 后续使用原码登录同一账户，不重复增加期限、重置积分或另建账户。兑换截止时间只限制首次激活；套餐到期后可登录查看已有乐谱、续期，但不恢复付费权限。
- 登录生成普通会话令牌和 HttpOnly 会话 Cookie，激活码不放入网址或浏览器本地存储。退出撤销当前会话。浏览器记住登录方式，会话失效后返回激活码入口。
- 新生成的码使用 128 位随机量。旧码继续兼容，登录接口按 IP 限制每 15 分钟 10 次，伪造或变换 Bearer 头不能绕过该限制。
- 已兑换到邮箱账户的旧码不会自动变成账户密码。用户在原账户登录后，明确点击“用此码开启免邮箱登录”，并通过归属校验，才允许该码登录原账户。
- 续期需先用原码登录，再展开“续期当前账户”兑换新码。同档套餐顺延，保留原账户；续期码不会自动增加为登录凭证，以后仍使用原登录码。
- 码遗失时依订单联系店铺。后台仍可查询订单和对应码；当前后台仅支持停用未兑换码，未新增已用码退款撤权或凭证轮换功能。

## 商家交付

后台仍为 <https://app.scoretransposer.com/cn/admin>，管理密码沿用现有私有交接文件。原四种月度、年度套餐和权益保持一致，复制的发货文案已改为直接用码登录，并说明保存凭证、续期方法。音频转五线谱仍未开放。
