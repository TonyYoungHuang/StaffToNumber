## 1. 产品目标

将现有的“PDF 五线谱转简谱”工具升级为浏览器端全功能乐谱平台，覆盖：

1. PDF、图片、扫描件上传后识别为可播放、可编辑乐谱。
2. 五线谱与简谱双向转换。
3. 按半音、目标调、声乐音域和移调乐器进行移调。
4. 五线谱可视化编辑、修谱、排版和版本管理。
5. 播放、变速、循环、节拍器、分声部练习和谱面跟随。
6. MusicXML、MIDI、PDF、SVG、PNG、MP3、WAV 导入导出。
7. 录音同步、波形、练习反馈和音频转谱。
8. 实时协作、课堂、作业、提交、批改、通知、资源库和 LMS。
9. 跨设备、免安装、可分享、可恢复、可观测的商业 SaaS 服务。
10. 面向中文市场的完整简谱体验，以及可持续获取自然流量的 SEO 内容体系。

## 2. 不可变架构原则

### 2.1 核心格式

- **Score JSON** 是编辑、版本、协作、播放和业务逻辑的应用内唯一事实来源。
- **MusicXML** 是主要交换格式，用于导入、导出及与 Audiveris、music21、MuseScore 等工具互操作。
- MIDI events、简谱、PDF、SVG、PNG、MP3、WAV 都是从 Score JSON 或 MusicXML 派生的投影或输出。
- PDF、图片、扫描件、录音和视频只作为输入素材，不允许直接作为可编辑乐谱的数据源。
- 所有 AI/OMR 结果必须先进入候选修订，不得未经用户确认直接成为正式修订。

### 2.2 技术职责

- **Audiveris**：PDF/图片 OMR，输出 MusicXML 和 `.omr` 诊断数据。
- **OpenSheetMusicDisplay**：MusicXML 浏览、分页、缩放、谱面预览和播放光标。
- **VexFlow**：专业编辑层、符号命中检测、拖动、键盘输入和交互排版。
- **music21**：复杂移调、调号/异名同音、MusicXML 验证、MIDI 清理和音乐理论计算。
- **Tone.js**：浏览器播放、变速、循环、节拍器、声部 solo/mute 和练习模式。
- **MuseScore CLI**：PDF/SVG/PNG 等高质量乐谱渲染和版面输出。
- **FluidSynth + SoundFont**：高质量 MIDI/Score 音频渲染。
- **ffmpeg**：MP3/WAV/OGG 转码、响度标准化、媒体探测和安全转码。
- **Basic Pitch**：音频转 MIDI 候选；后续经 music21 清理后进入 Score JSON 候选。
- **yt-dlp**：受版权、域名白名单和用户授权约束的视频/音频链接导入。
- **Yjs + Hocuspocus**：Score JSON 协同编辑、在线状态、共享撤销和冲突合并。

## 5. 商用投产 100% 完成定义

项目只有同时满足以下条件，才允许在文档和官网标记为“商用投产完成”：

### 5.1 功能闭环

- 十类核心用户流程全部通过桌面端和移动端端到端测试。
- 任一导入都能得到成功结果、可修复候选或明确失败原因，不允许永久排队和静默失败。
- 所有编辑都进入版本历史，可撤销、重做、恢复，并能导出为有效 MusicXML。
- 播放、移调、简谱和导出基于同一 Score JSON 修订，结果不得互相漂移。
- 免费、专业版、学校版的能力、配额、水印、存储和并发限制真实执行。

### 5.2 音乐正确性

- 建立至少 200 份覆盖钢琴、声乐、合唱、管弦、多声部、移调乐器、简谱和复杂反复的合法测试谱库。

## 10. 目标生产架构

```text
Browser
  |-- www/app (Vercel or equivalent edge hosting)
  |-- API (container, stateless, horizontal scaling)
  |-- Collaboration WebSocket (Hocuspocus cluster)
  |-- Object Storage (source, candidate, export, media)
  |-- PostgreSQL (documents, revisions, jobs, billing, education)
  |-- Redis + durable queue (locks, jobs, presence, rate limits)
  `-- Worker pools
       |-- OMR: Audiveris
       |-- Music: music21 / MuseScore
       |-- Audio: FluidSynth / ffmpeg
       `-- AI: Basic Pitch / yt-dlp restricted importer
```

生产环境至少分为 `development`、`staging`、`production`。重型 Worker 按任务类型拆队列并设置独立并发，禁止在 Vercel Function 内运行 Audiveris、MuseScore、Basic Pitch、FluidSynth 或长音频转码。
