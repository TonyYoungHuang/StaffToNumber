## Acceptance rules

1. Read the destination’s posting and disclosure rules before contact.
2. Personalize every pitch around a specific existing resource or reproducible technical issue.
3. Offer the reference asset or correction even if the editor chooses not to link.
4. Disclose affiliation with ScoreTransposer.
5. Never buy links, automate mass outreach, request keyword-rich anchors, or create fake accounts/reviews.
6. Record the live third-party URL and publication date before counting a backlink.
